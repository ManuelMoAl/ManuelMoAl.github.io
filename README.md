# Datos & territorio

Portafolio de Manuel Morales Almora dedicado a explorar los datos y su relación con el territorio.

**Visita el sitio:** [manuelmoal.github.io](https://manuelmoal.github.io/)

El portafolio reúne tres áreas de interés:

- **Estadística y Ciencia de Datos:** exploración, modelado y visualización de información.
- **Análisis Espacial y SIG:** patrones territoriales y análisis de información geográfica.
- **GeoWeb:** cartografía y experiencias de exploración en la web.

El sitio está desarrollado en HTML, CSS y JavaScript y está destinado a publicarse mediante GitHub Pages.

El mapa de portada representa las 32 entidades de México en escala de grises con valores ficticios de carácter ilustrativo. Los proyectos identificados como ejemplos presentan propuestas de análisis, no resultados de estudios realizados.
